I built a tool that turns a web app into a desktop app for demos — backend and database included.

The problem: when a product owner wants to try a new feature, they wait for a deployment. The branch needs a test environment, a working backend, a database with test data. Feedback that could take five minutes takes a day.

The solution: send them the app. They unzip it, double-click, and try the feature on their own laptop. No deployment, no server, no Docker.

How web-terrarium does it:

Unchanged web server — your Next.js server (or a Vite app's build) runs inside Electron, on 127.0.0.1. The same build you'd deploy, just on a laptop.

Extra servers — a mock API or a database starts next to it. Ports are picked at start-up, and placeholders like {port:db} wire them together.

PostgreSQL inside the app — the example is a full-stack Next.js app with Prisma. Its database runs in the app as PGlite (PostgreSQL compiled to WebAssembly), seeded fresh on every launch.

Safe to hand out — servers only listen on 127.0.0.1, the window is sandboxed, and .env files never ship.

Builds in CI — a GitHub Actions workflow builds the Windows and Mac apps on every pull request and comments the download links.
